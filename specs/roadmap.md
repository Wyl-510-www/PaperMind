# Roadmap V3 — 精简聚焦版

**更新日期**：2026-10-08

**设计原则**：
- 聚焦单一核心场景：论文阅读笔记管理
- 渐进式功能增强，每个 Phase 独立可验收
- 不设定固定时间表，按节奏逐步推进
- 最小化技术依赖，保持架构简洁

---

## 核心场景

### 论文阅读笔记管理

> 用户阅读论文 → 在外部工具（Notion、Word）整理笔记 → 上传笔记 PDF 到 PaperMind → 输入元数据（标题、标签、日期）→ 系统提取并保存 → 跨会话查询"我对 XX 论文的理解是什么？"

**研究领域**：NLP 中的长期记忆管理

**关键设计决策**：
- ✅ 整篇笔记作为一条 Fact（不拆分段落）
- ✅ 预定义标签库（扁平化，10-20 个标签）
- ✅ 检索策略：标签过滤 → 语义检索
- ✅ 只使用 Fact Lane（笔记和知识点）
- ❌ 暂不处理图片（纯文本提取）
- ❌ 不做任务规划功能

## 后续阶段规划

### Phase 3：元数据管理与标签过滤

**目标**：完善笔记的元数据管理，支持按标签和时间过滤检索。

**核心功能**：

#### 3.1 扩展元数据字段
- 论文标题（必填）
- 作者（选填）
- 发表年份/会议（选填）
- 阅读日期（自动填充当天，可修改）
- 标签（多选，来自预定义标签库）
- 笔记类型（摘要、详细笔记、评论、问题）

#### 3.2 预定义标签库设计
**研究领域**：NLP 中的长期记忆管理

**标签列表（扁平化，10-20 个）**：
- 长期记忆
- 记忆架构
- 知识图谱
- 向量数据库
- RAG（检索增强生成）
- Agent 智能体
- 多模态记忆
- 个性化
- 上下文管理
- Transformer
- 注意力机制
- 嵌入技术
- 评测基准
- 应用案例
- 理论基础

*注：可在实施过程中根据实际需求调整*

#### 3.3 检索策略优化
**两阶段检索**：
1. **硬过滤**（标签 + 时间范围）
   - 用户选择标签：单选或多选
   - 时间范围下拉菜单：全部时间 / 本周 / 本月 / 本年 / 自定义日期
   - 从 MySQL 过滤出符合条件的 Memory IDs
   
2. **语义检索**（向量相似度）
   - 对过滤后的结果进行 embedding 检索
   - Reranker 精排
   - 返回最相关的笔记

**特殊情况**：
- 如果未选择标签和时间，直接进行全局语义检索（当前行为）
- 如果过滤后无结果，提示"未找到符合条件的笔记"

#### 3.4 Streamlit UI 更新
- 笔记输入页面：增加元数据输入表单
- 查询页面：增加标签多选框 + 时间范围下拉菜单
- 笔记展示：显示完整元数据（标签、作者、日期等）

### Phase 6：笔记编辑与版本管理

**目标**：支持修改笔记内容和元数据、删除错误记录、查看历史版本。

**核心功能**：

#### 6.1 笔记列表与详情浏览
- 展示所有笔记列表（表格形式）
- 列展示：论文标题、标签、阅读日期、笔记类型
- 支持排序（按日期、标题）
- 点击查看笔记详情（完整内容 + 元数据）
- 搜索框：按标题快速搜索

#### 6.2 笔记编辑功能
- 编辑笔记内容（纯文本编辑器）
- 编辑元数据（标题、标签、作者、年份、日期、类型）
- 保存时创建新版本（Memory V2 原生支持版本化）
- 显示"最后修改时间"

#### 6.3 笔记删除
- 软删除（标记为已删除，不再出现在检索和列表中）
- 删除前二次确认
- 可选：硬删除（物理删除 Memory 记录）

#### 6.4 版本历史
- 查看笔记的修改历史（版本列表）
- 对比版本差异（文本 diff）
- 回滚到指定版本
- 恢复已删除笔记

### Phase 8：批量导入优化

**目标**：支持一次上传多个笔记 PDF，减少重复操作。

**核心功能**：

#### 8.1 批量上传
- 选择多个 PDF 文件（文件选择器支持多选）
- 显示文件列表（文件名、大小、状态）
- 移除列表中的文件（上传前）

#### 8.2 批量元数据输入
- 两种模式：
  - **统一模式**：所有文件使用相同标签和笔记类型（快速导入）
  - **逐个模式**：为每个文件单独输入元数据（精确控制）
- 默认值填充：阅读日期统一为当天

#### 8.3 批量处理与进度
- 显示导入进度条（已处理 X / 共 Y 个）
- 实时显示每个文件的状态：等待、处理中、成功、失败
- 失败时显示错误原因（文件损坏、提取失败等）
- 完成后显示汇总：成功 X 个，失败 Y 个

#### 8.4 结果确认
- 导入完成后展示笔记列表（可跳转到详情）
- 失败文件可重新尝试或跳过

**实施步骤**：

**Step 1**：批量上传 UI（1 天）
- [ ] 多文件选择器
- [ ] 文件列表展示（可移除）
- [ ] 元数据输入模式切换（统一 vs 逐个）

**Step 2**：批量处理逻辑（1 天）
- [ ] 遍历文件列表，逐个提取和保存
- [ ] 异步处理（避免阻塞 UI）
- [ ] 错误捕获和记录

**Step 3**：进度与状态展示（0.5 天）
- [ ] 进度条更新
- [ ] 文件状态实时更新
- [ ] 失败文件错误信息展示

**Step 4**：测试与验收（0.5 天）
- [ ] 上传 5 个正常 PDF，全部成功
- [ ] 上传包含损坏文件的批次，显示失败信息
- [ ] 测试统一模式和逐个模式
- [ ] 验证所有笔记正确保存

**验收标准**：
- ✅ 可一次选择多个 PDF 文件
- ✅ 支持统一元数据和逐个输入两种模式
- ✅ 显示实时处理进度和状态
- ✅ 失败文件有明确错误提示
- ✅ 完成后显示汇总结果

### Phase 7：笔记导出与分享

**目标**：导出笔记为 Markdown 或 JSON，支持备份和分享。

**核心功能**：

#### 7.1 单条笔记导出
- 导出为 Markdown 格式
- 包含元数据（frontmatter）
- 格式示例：
```markdown
---
title: "Attention Is All You Need 阅读笔记"
author: "Vaswani et al."
year: 2017
tags: [Transformer, 注意力机制]
read_date: 2026-10-08
note_type: 详细笔记
---

[笔记内容]
```

#### 7.2 批量导出
- 选择多条笔记（复选框）
- 导出为单个 ZIP 文件（每条笔记一个 Markdown 文件）
- 或导出为单个 JSON 文件（结构化数据）

#### 7.3 全部导出
- 导出所有笔记
- 生成索引文件（README.md，列出所有笔记）
- 按标签分文件夹组织

#### 7.4 导入兼容性（可选）
- 导出的 Markdown 可被其他工具读取（Obsidian、Notion）
- 导出的 JSON 可被重新导入 PaperMind

**实施步骤**：

**Step 1**：Markdown 导出（1 天）

- [ ] JSON 导出选项

**Step 3**：全部导出与索引（0.5 天）

- [ ] 导出单条笔记，验证 Markdown 格式

**验收标准**：
- ✅ 单条笔记可导出为 Markdown

## 技术决策

### 保持现有技术栈
- **Python 3.11+**
- **Memory V2**（只使用 Fact Lane）
- **Streamlit**（UI 框架）
- **PyMuPDF**（PDF 文本提取）
- **DashScope (Qwen)**（LLM 和 Embedding）
- **Qdrant**（向量检索）
- **MySQL**（结构化存储）

### 新增依赖（最小化）
- **Phase 3**：无新增依赖（使用 Python 标准库处理日期）
- **Phase 6**：`difflib`（Python 标准库，文本对比）
- **Phase 8**：无新增依赖
- **Phase 7**：`zipfile`（Python 标准库，打包导出）

### 明确不包含
- ❌ 图片处理（Phase 4 删除）
- ❌ 任务规划功能（Phase 5 删除）
- ❌ 多 Lane 支持（Event/Strategy Lane）
- ❌ 前后端分离（Phase 9 延期）
