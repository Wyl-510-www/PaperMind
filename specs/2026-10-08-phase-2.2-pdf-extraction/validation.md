## 2. 端到端集成测试

### 2.1 完整流程验证

**前置条件**：
- MySQL、Qdrant 服务已启动
- Streamlit 应用正在运行
- 准备 3 份测试 PDF：正常论文、加密 PDF、扫描版 PDF

**测试步骤**：

#### 场景 A：正常 PDF 提取与保存

```
1. 启动 Streamlit 应用
2. 选择身份：tenant_A / user_A
3. 点击"上传 PDF 论文"
4. 上传测试 PDF（如 Attention Is All You Need.pdf）
5. 验证：自动提取标题和文本
6. 验证：显示前 500 字符预览
7. 编辑提取的内容（可选）
8. 点击"确认保存"
9. 验证：保存成功，显示 Memory ID
10. 点击"同步一批"
11. 验证：同步完成
```

**预期结果**：
- ✅ 标题字段自动填充
- ✅ 内容预览清晰可读
- ✅ 保存成功，返回 Memory ID
- ✅ 临时文件已删除（检查 `tmp/uploads/` 目录）

---

#### 场景 B：跨会话检索

```
1. 在 Streamlit 点击"新建会话"（或刷新页面）
2. 重新选择身份：tenant_A / user_A
3. 在查询框输入："我之前记录过 Transformer 相关的论文吗？"
4. 点击"查询历史记忆"
```

**预期结果**：
- ✅ 返回刚才保存的论文笔记
- ✅ 显示实际 Memory ID 和内容
- ✅ 答案基于检索证据，不编造

---

#### 场景 C：错误处理

```
1. 上传加密 PDF
   预期：提示"PDF 已加密，无法提取文本"
   
2. 上传扫描版 PDF
   预期：提示"检测到扫描版 PDF，暂不支持 OCR"
   
3. 上传非 PDF 文件（如 .txt）
   预期：Streamlit 文件上传限制或明确错误提示
   
4. 上传超大文件（>10MB）
   预期：文件上传被拒绝或提示文件过大
```

**预期结果**：
- ✅ 每种错误都有明确提示
- ✅ 错误不导致应用崩溃
- ✅ 用户可切换回手动输入

---

### 2.2 身份隔离验证

```
1. 以 tenant_A / user_A 上传并保存 PDF_A
2. 切换身份到 tenant_A / user_B
3. 查询 PDF_A 相关内容
   预期：未找到相关历史记忆
   
4. 切换身份到 tenant_B / user_A
5. 查询 PDF_A 相关内容
   预期：未找到相关历史记忆
```

**预期结果**：
- ✅ 不同身份无法读取彼此的 PDF 笔记
- ✅ Memory ID 和内容完全隔离

## 7. 已知限制与边界

### 7.1 接受的限制

以下情况明确提示，不视为缺陷：

- 扫描版 PDF 无法提取文本
- 图表、公式无法解析
- 复杂排版可能影响文本顺序
- 仅支持单文件上传
- 不保存原始 PDF 文件

### 7.2 不接受的情况

以下必须修复：

- 正常 PDF 提取失败但无错误提示
- 提取后应用崩溃
- 临时文件未清理导致磁盘占满
- 跨用户读取他人上传的内容
- 破坏现有保存或检索流程
